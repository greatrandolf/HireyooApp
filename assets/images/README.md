# Dashboard Image

Place your Hireyoo dashboard screenshot here as `dashboard.png`

## Requirements
- **File name:** dashboard.png
- **Location:** assets/images/dashboard.png
- **Format:** PNG (recommended) or JPG
- **Dimensions:** 1200px × 800px (or maintain aspect ratio)
- **Size:** < 500KB recommended
- **Content:** Screenshot of the Hireyoo payroll dashboard interface

## Usage
The image is referenced in the landing page at:
- `src/screens/auth/landing/LandingPage/index.html`
- Image path: `/assets/images/dashboard.png`

This path works for:
- ✅ Web (Expo web)
- ✅ Native (iOS/Android) via WebView
- ✅ Development and production builds
